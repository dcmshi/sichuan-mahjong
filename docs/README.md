# docs/ — what is in here, and where the outside facts came from

Two things: an index of this directory, and **the register of every source
outside this repo that a decision rests on**.

The register exists because links rot and this project settles rule disputes by
citation. Each row therefore records *what the source was used to establish*, not
just its address — so if the page disappears, the claim is still traceable and
the next person knows what to go looking for rather than what to click.

## The ruleset

**No single source is authoritative, and the PDF is not gospel.** Sichuan mahjong
is a family of regional and app-specific variants; two of the divergences this
project has recorded (`fanCap`, 龙七对) are places where sources genuinely
disagree and neither reading is wrong. The method is therefore always the same:
**the PDF plus at least one source outside it, per claim**, with a decision
recorded when they differ.

### The 番 conventions, because sources cannot be compared without this

Three are in circulation and they produce different numbers for the same hand:

- **Exponent** (ours, and the PDF's): hand value is `2^fan`, so 0 fan = 1 point.
- **1-indexed** (E, and most Chinese apps): 平胡 = 1番, multiplier `2^(番−1)`.
- **番 as the multiplier itself**: gives readings like "清七对 48番".

Compare **doublings**, which is convention-free. See
[audit-payments.md §7](./audit-payments.md).

## Security advisories

| Source | For |
|---|---|
| [GitHub Advisory Database](https://github.com/advisories), consulted via `pnpm audit` | **Every version floor in this repo.** A77 found ten production vulnerabilities on the live URL, nine high — the load-bearing one being `ws` >=8.0.0 <8.21.0, *memory exhaustion from many small fragments*, which is what this service is. `maxPayload` does not cover it: that caps a message, the attack accumulates fragments. Three fixes are transitive and live as overrides in `pnpm-workspace.yaml`, each pinned to **the first patched version rather than `latest`**, so the override states its reason and expires when the parent catches up |

**Pin to the advisory's range, not past it.** A77's first `brace-expansion`
override was widened on the reasoning that a small package's majors are cheap;
5.x moved off a CommonJS default export and broke `minimatch@9`, and lint,
typecheck, 738 unit tests and all 12 e2e specs passed anyway — the only thing
here that walks a glob is the coverage reporter. A validation suite is only as
wide as the paths it touches.
